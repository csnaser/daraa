# درء (Daraa)

حماية ذكية تبدأ قبل الدفع

تطبيق نموذجي (Prototype) للحماية من الاحتيال الرقمي، يساعد المستخدم على اكتشاف الروابط المشبوهة، والحسابات البنكية المزيفة، ومواقع التصيّد الاحتيالي، قبل أن يقع ضحية لعملية نصب، لا بعدها.

## المشكلة

يتطور الاحتيال الرقمي والمالي يومًا بعد يوم: روابط شحن وهمية، مواقع تسوّق مزيفة، حسابات بنكية مشبوهة لاستلام الأموال، ورسائل تنتحل صفة جهات رسمية. ولا يملك المستخدم العادي أداة سريعة وبسيطة يتحقق من خلالها قبل أن يضغط على رابط أو يحوّل أمواله.

## الحل

يقدّم "درء" أداة فحص فورية تمنح المستخدم تقييمًا واضحًا (آمن، مشبوه، أو خطر) لأي رابط، أو موقع إلكتروني، أو رقم حساب بنكي (IBAN)، أو رمز استجابة سريعة (QR)، مع توصية عملية بالخطوة التالية، وإمكانية رفع بلاغ ومتابعة حالته.

## أبرز المزايا

- فحص فوري لأنواع متعددة من المخاطر: الروابط، المواقع والمتاجر الإلكترونية، الحسابات البنكية (IBAN)، ورموز الاستجابة السريعة.
- مساعد "درء" الذكي: يمكن سؤاله عن أي رابط أو رسالة أو موقف مشبوه للحصول على تقييم وتوصية فورية.
- مركز البلاغات: إمكانية رفع بلاغ ومتابعة حالته عبر مراحل واضحة، من المراجعة الأولية إلى القرار النهائي.
- عرض تجريبي للتكامل البنكي: محاكاة لإشعارات الدفع المشبوهة والتحقق التلقائي من الحسابات قبل إتمام التحويل، ضمن خارطة الطريق المستقبلية للتطبيق.
- دعم كامل للغتين العربية والإنجليزية، مع تبديل فوري لاتجاه الواجهة.
- واجهة مصممة بالكامل على هيئة تطبيق هاتف حقيقي، دون الحاجة إلى أي تحميل أو تثبيت.

## التقنيات المستخدمة

ملف واحد مستقل بلغات HTML وCSS وJavaScript، دون الاعتماد على أي إطار عمل أو خادم خلفي، ويعمل مباشرة من المتصفح على أي جهاز.
